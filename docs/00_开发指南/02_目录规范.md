# 目录规范

> 本文档定义 GodotScaffolding 的目录结构与各阶段交付物归属。AI 进行任何开发时，**必须**按本规范放置文件。
> 配合 `AGENTS.md` 的「游戏迭代开发主流程（端到端）」使用。

---

## 一、设计原则

1. **按文件性质分目录**：`scripts/`=所有 `.gd` 脚本、`scenes/`=所有 `.tscn` 场景、`assets/`=媒体资源、`data/`=`.tres` 数据实例、`shaders/`=`.gdshader`
2. **docs 编号对齐流程阶段**：文档目录序号与「游戏迭代开发主流程」10 阶段顺序一致
3. **测试镜像源码**：`test/unit/` 子目录必须与功能代码相对路径完全一致
4. **临时产物隔离**：`build/`、`.tmp/` 仅存临时产物，任务结束删除
5. **场景就近脚本**：实体场景与其专属脚本放同一目录（co-locate）

---

## 二、完整目录树

```
GodotScaffolding/
├── project.godot                  # Godot 工程配置（阶段7前必建）
├── export_presets.cfg             # web 导出预设（阶段10）
├── AGENTS.md                      # 项目宪法（含开发主流程）
├── MEMORY.md                      # 经验沉淀（横切 C3）
├── README.md
│
├── docs/                          # ───── 文档类交付物 ─────
│   ├── 00_开发指南/               # 流程/目录规范/快速开始/环境（非阶段专属）
│   ├── 01_创意探索/               # 阶段1：创意文档
│   ├── 03_资产/                   # 阶段2：资产清单 + 阶段3：精灵资源文档
│   ├── 04_高保真设计/             # 阶段4：HTML+gsap 交互原型
│   ├── 05_需求/                   # 阶段5：Feature + 验收标准 AC
│   ├── 06_story/                  # story 拆分 + 00_总表.md
│   ├── 07_架构/                   # 阶段7：架构方案
│   └── 08_验收/                   # 阶段10：验收报告（可选）
│
├── scenes/                        # ───── 所有 .tscn 场景（按实体类型）─────
│   ├── actors/                    # 角色/敌人/NPC
│   ├── levels/                    # 关卡/世界
│   ├── objects/                   # 交互物体
│   ├── ui/                        # UI 场景
│   └── components/                # 可复用组件场景
│
├── scripts/                       # ───── 所有 .gd 脚本 ─────
│   ├── classes/                   # 基类
│   ├── utils/                     # 工具函数
│   ├── autoloads/                 # 全局单例
│   └── resources/                 # Resource 类定义（extends Resource）
│
├── assets/                        # ───── 媒体资源（无代码）─────
│   ├── sprites/                   # 精灵（characters/environment/ui）
│   ├── audio/                     # 音频（music/sfx）
│   ├── fonts/                     # 字体
│   ├── textures/                  # 纹理
│   └── themes/                    # 主题
│
├── data/                          # .tres 数据实例（Resource 的具体取值）
├── shaders/                       # .gdshader 着色器
├── addons/                        # 插件（GdUnit4 等）
│
├── test/                          # ───── 测试（分层 + 镜像）─────
│   ├── unit/                      # 单元测试（子目录镜像功能代码相对路径）
│   └── integration/               # 集成测试
│
├── build/                         # web 导出产物（临时，验后删）
└── .tmp/                          # 验收证据/中间产物（临时，任务后删）
```

## 三、docs 编号体系（对齐 10 阶段）

| 目录 | 对应阶段 | 内容 |
|------|---------|------|
| `00_开发指南/` | — | 流程、目录规范、快速开始、环境配置 |
| `01_创意探索/` | 阶段 1 | 创意文档（意图/约束/成功标准） |
| `03_资产/` | 阶段 2 + 3 | 资产清单、精灵资源文档（tile/帧分组） |
| `04_高保真设计/` | 阶段 4 | HTML + gsap 交互原型 |
| `05_需求/` | 阶段 5 | Feature 文档 + 验收标准 AC |
| `06_story/` | 阶段 5 延伸 | story 拆分 + `00_总表.md` |

## 四、工程目录用途

| 目录 | 存放 | 说明 |
|------|------|------|
| `scenes/` | `.tscn` | 按实体类型（actors/levels/objects/ui）组织，**禁止**按节点类型分 |
| `scenes/components/` | `.tscn` | 可复用组件场景（如 health_component.tscn） |
| `scripts/` | `.gd` | 所有脚本：classes/utils/autoloads/resources |
| `scripts/autoloads/` | `.gd` | 全局单例（在 project.godot 注册 Autoload），保持精瘦 |
| `scripts/resources/` | `.gd` | `extends Resource` 的类定义（非实例） |
| `assets/` | 媒体 | sprites/audio/fonts/textures/themes，**纯资源无代码** |
| `data/` | `.tres` | Resource 实例（具体取值，引用 `scripts/resources/` 的类） |
| `shaders/` | `.gdshader` | 着色器 |
| `addons/` | 插件 | 第三方/自定义编辑器插件（GdUnit4 等） |
| `test/unit/` | `_test.gd` | 单元测试，**镜像源码路径**（见第六节） |
| `test/integration/` | `_test.gd` | 集成测试（多模块协作） |

## 六、单元测试镜像规则（强制）

`test/unit/` 下的子目录必须与功能代码**相对路径完全一致**，文件名加 `_test` 后缀：

| 功能代码 | 对应单测 |
|---------|---------|
| `scripts/utils/math_utils.gd` | `test/unit/scripts/utils/math_utils_test.gd` |
| `scripts/autoloads/game_manager.gd` | `test/unit/scripts/autoloads/game_manager_test.gd` |
| `scripts/resources/item_data.gd` | `test/unit/scripts/resources/item_data_test.gd` |
| `scenes/actors/player/player.gd` | `test/unit/scenes/actors/player/player_test.gd` |

集成测试放 `test/integration/`，按测试场景命名，不强制镜像。

## 七、命名规范

| 类型 | 约定 | 示例 |
|------|------|------|
| 文档（docs） | `{两位序号}_{中文名称}.md` | `01_快速开始.md` |
| 目录 | `snake_case` | `player_states/` |
| 场景 | `snake_case.tscn` | `main_menu.tscn` |
| 脚本 | `snake_case.gd` | `player_controller.gd` |
| Resource 实例 | `snake_case.tres` | `fire_sword.tres` |
| 着色器 | `snake_case.gdshader` | `water_ripple.gdshader` |
| 图片 | `snake_case.png` | `player_idle.png` |
| 音频 | `snake_case.wav/ogg` | `jump_sound.wav` |
| 单测 | `{源名}_test.gd` | `math_utils_test.gd` |

## 八、临时目录约定

| 目录 | 用途 | 生命周期 |
|------|------|---------|
| `build/` | Godot web 导出产物 | 阶段 10 验收后**立即删除**，已加入 `.gitignore` |
| `.tmp/` | 验收截图、console 日志、lint 报告等中间产物 | 单个任务/阶段完成后**立即删除** |

> **禁止**将临时产物散落到其他目录；**禁止**提交 `build/`、`.tmp/` 到 git。
